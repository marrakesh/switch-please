# Switch Please

[![CI](https://github.com/marrakesh/switch-please/actions/workflows/ci.yml/badge.svg)](https://github.com/marrakesh/switch-please/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Перемикач розкладки для Windows у дусі Punto Switcher. Виправляє текст, набраний не в тій
розкладці — гарячою клавішею або автоматично.

**[English](README.md)** · **[Русская](README.ru.md)** · **[Deutsch](README.de.md)** · **[Čeština](README.cs.md)**

![Набирається «ghbdtn rfr ltkf», подвійний Shift, виходить «привет как дела»](docs/demo.svg)

## Що робить

| | |
|---|---|
| **Подвійний Shift** | Виправляє останнє слово і перемикає розкладку |
| **Подвійний Ctrl** | Виправляє виділене, а якщо нічого не виділено — весь рядок |
| Скасування | Повертає останнє виправлення. Типово не призначене |
| Автоматично | Типово вимкнено, вмикається в меню трея |

Усі три комбінації перепризначаються, діалог ловить справжнє натискання. Backspace знімає
призначення. Інтерфейс англійською, російською, українською, німецькою та чеською, тема —
за налаштуванням Windows.

## Приклади

| Вийшло | Хотіли | |
|---|---|---|
| `ghbdsn` | привіт | українська на англійській розкладці |
| `vscnj` | місто | українська на англійській розкладці |
| `ufhyj` | гарно | українська на англійській розкладці |
| `руддщ` | hello | англійська на українській розкладці |
| `привыт` | привіт | українська на російській розкладці |
| `мысто` | місто | українська на російській розкладці |

Останні два — найскладніший випадок: українська та російська розкладки різняться трьома
клавішами, тож результат лишається звичайною кирилицею, і статистика літер його не
розрізняє. Розрізняє словник Windows — такого російського слова не існує.

Навмисно не чіпає: слова коротші за три літери, слова з цифрами, шляхи (`C:\Windows`),
адреси (`user@example.com`), `camelCase` — і текст мовою, для якої немає ні вбудованої
моделі, ні словника Windows: там перемикач утримується, а не вгадує.

## Встановлення

Завантажте з [Releases](https://github.com/marrakesh/switch-please/releases) і запустіть.
Інсталятор не потрібен.

| Файл | Розмір | Потребує |
|---|---|---|
| `SwitchPlease.exe` | ~52 МБ | нічого |
| `SwitchPlease-runtime-required.exe` | ~0.4 МБ | [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) |
| `SwitchPlease-arm64.exe` | ~50 МБ | нічого, на ARM-машині |
| `SwitchPlease-arm64-runtime-required.exe` | ~0.4 МБ | ARM64-версію Desktop Runtime |

Файли **не підписані**, тож SmartScreen попередить під час першого запуску. У кожному релізі
є `SHA256SUMS.txt`, зібраний тим самим прогоном, що й самі файли:
`certutil -hashfile SwitchPlease.exe SHA256`.

Запускати **без прав адміністратора**: інакше виправлення перестануть доходити до звичайних
вікон. Потрібна Windows 10 або новіша.

## Приватність

**Жодних мережевих запитів.** Ні телеметрії, ні аналітики, ні звітів про збої. Єдине місце,
де відкривається сокет, — перевірка оновлень: вона запитує в GitHub номер останнього релізу,
не повідомляє про вас нічого і **типово вимкнена**.

Набране не залишає машину і типово не пишеться на диск: до журналу потрапляють рішення, а
текст скорочено до довжини. Самі слова з'являться, лише якщо увімкнути *Записувати набраний
текст до журналу*.

## Налаштування

Основне — у меню трея, числа — у *Налаштування...*, усе разом лежить у
`%APPDATA%\SwitchPlease\settings.json`. Повний опис кожного параметра —
[в англійській версії](README.md#settings).
