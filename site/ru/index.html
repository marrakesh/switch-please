Набрали не в той раскладке? Нажмите Shift дважды.

Набрали ghbdtn, а хотели привет, или руддщ вместо hello? Switch Please наберёт слово заново так, как вы хотели, и переключит раскладку — можно печатать дальше.

Скачать для Windows Версии для ARM64 и портативные

Бесплатно и с открытым кодом · Windows 10 и 11 · Без прав администратора

Что умеет

Две горячие клавиши

Shift ×2 исправляет последнее слово, Ctrl ×2 — выделение или всю строку. Нажмите Shift ×2 ещё раз сразу же — и слово вернётся.

Автоисправление — когда оно нужно

По умолчанию выключено. Если включить, исправляет каждое слово, как только вы его закончили, — везде или только в выбранных приложениях.

Не трогает правильный текст

На обычной прозе, слово за словом, не переписало ни одного из 233 правильно набранных слов. Пропущенное исправление стоит одного нажатия, испорченное слово — гораздо дороже.

Отличает русский от украинского

привыт и привіт — одинаково правдоподобная кириллица; какое из них слово, знает только словарь.

Любой установленный язык

Русский, украинский и английский работают сразу, как и любой другой язык, для которого в Windows есть словарь проверки орфографии.

Забытый Caps Lock

пРИВЕТ превращается в Привет, а Caps Lock выключается. Заглавные, набранные намеренно, остаются как есть.

Запоминает, что не трогать

Отмените автоисправление — и слово больше не будет исправляться автоматически: фамилия, логин, слово на языке без модели.

Не лезет куда не надо

Поля паролей, полноэкранные игры, терминалы, редакторы кода и менеджеры паролей программа не трогает с самого начала.

Раскладка у курсора

По желанию: при смене раскладки под текстовым курсором на мгновение появляется маленькая метка RU или EN.

Как начать

  1. УстановитеЗапустите SwitchPlease-Setup.exe. Программа ставится только для вас, не просит прав администратора и предлагает запускаться вместе с Windows.
  2. Найдите значокПрограмма живёт в области уведомлений, значок показывает текущую раскладку. Не видно? Он под стрелкой ^ — перетащите его на панель задач.
  3. ПечатайтеНе та раскладка? Shift ×2 — для последнего слова, Ctrl ×2 — для выделения или строки.

При первом запуске Windows SmartScreen предупредит. Файлы пока не подписаны, поэтому один раз придётся нажать Подробнее → Выполнить в любом случае. В каждом релизе есть SHA256SUMS.txt для проверки загрузки, а политика подписи кода (на английском) рассказывает, как настраивается подпись.

Приватность

Никакой телеметрии, аналитики, отчётов о сбоях и проверки лицензии. Единственный сетевой запрос — проверка обновлений: она спрашивает у GitHub тег последнего релиза, ничего о вас не отправляет и по умолчанию выключена.

Ничего из набранного не покидает компьютер, и по умолчанию на диск пишутся только настройки. Код открыт — подробности в README.
