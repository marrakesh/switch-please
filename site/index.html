Typed in the wrong layout? Press Shift twice.

Typed ghbdtn when you meant привет, or руддщ when you meant hello? Switch Please retypes the word the way you meant it and switches the layout, so you can carry on typing.

Download for Windows ARM64 and portable versions

Free and open source · Windows 10 and 11 · No administrator rights

What it does

Two hotkeys

Shift ×2 fixes the last word, Ctrl ×2 the selection or the whole line. Changed your mind? Press Shift ×2 again straight away and the word is put back as it was.

Automatic correction, when you want it

Off by default. Switched on, Switch Please fixes each word as you finish it — everywhere, or only in the applications you choose.

Leaves correct text alone

Switch Please rewrites a word automatically only when there is no doubt you typed it in the wrong layout. In a test on ordinary text, none of 233 correctly typed words was touched. If a word is still in the wrong layout, press Shift ×2.

Tells Russian from Ukrainian

ghbdsn is привыт in the Russian layout and привіт in the Ukrainian one. Both look like Cyrillic words, so Switch Please checks the dictionary and picks the one that exists.

Any language you have installed

Russian, Ukrainian and English work out of the box, and so does any other language Windows has a spell-check dictionary for.

Caps Lock left on

пРИВЕТ becomes Привет, and Caps Lock is switched off. Words typed in capitals on purpose stay as they are.

Learns what to leave alone

Automatic correction touched a word it should have left alone: a surname, a login, a word in a language Switch Please does not know? Press Shift ×2 to put it back, and from then on that word is never corrected automatically again.

Stays out of the way

Out of the box, Switch Please does nothing in password fields, full-screen games, terminals, code editors and password managers.

The layout at the cursor

If you like, a small RU or EN tag appears under the text cursor for a moment whenever the layout changes.

Getting started

  1. InstallRun SwitchPlease-Setup.exe. Switch Please installs for you alone, asks for no administrator rights, and offers to start with Windows.
  2. Find the iconSwitch Please lives in the notification area and shows the current layout. Not there? It is under the ^ arrow; drag it onto the taskbar.
  3. TypeWrong layout? Shift ×2 for the last word, Ctrl ×2 for the selection or the line.

Windows SmartScreen will warn the first time. The files are not code-signed yet, so More info → Run anyway is needed once. Every release has a SHA256SUMS.txt to check a download against, and the code signing policy says how signing is being set up.

Private

No telemetry, no analytics, no crash reporting, no licence check. The only network request it can make is the update check: it asks GitHub for the latest release tag, sends nothing about you, and is off by default.

Nothing you type leaves your computer, and by default nothing is written to disk but the settings. The source is open — the details are in the README.
