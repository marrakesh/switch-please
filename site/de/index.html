Im falschen Layout getippt? Drücken Sie zweimal Shift.

Ywiebel getippt, aber Zwiebel gemeint, oder zes statt yes? Switch Please tippt das Wort so neu, wie Sie es gemeint haben, und schaltet das Layout um, sodass Sie gleich weitertippen können.

Für Windows herunterladen ARM64- und portable Versionen

Kostenlos und quelloffen · Windows 10 und 11 · Keine Administratorrechte

Was es kann

Zwei Tastenkürzel

Shift ×2 korrigiert das letzte Wort, Strg ×2 die Auswahl oder die ganze Zeile. Gleich danach noch einmal Shift ×2, und das Wort ist zurück.

Automatische Korrektur, wenn Sie sie wollen

Standardmäßig aus. Eingeschaltet korrigiert sie jedes Wort, sobald es fertig getippt ist — überall oder nur in den Anwendungen, die Sie auswählen.

Lässt korrekten Text in Ruhe

Die automatische Korrektur lässt lieber ein Wort aus, als eines zu verderben. In einem Test mit gewöhnlichem Text blieben alle 233 richtig getippten Wörter unangetastet. Ein ausgelassenes Wort kostet Sie ein Shift ×2, ein richtiges Wort, das fälschlich „korrigiert“ wurde, weit mehr.

Jede installierte Sprache

Russisch, Ukrainisch und Englisch funktionieren ohne Einrichtung, ebenso Deutsch und jede andere Sprache, für die Windows ein Rechtschreibwörterbuch hat.

Unterscheidet Russisch von Ukrainisch

ghbdsn ergibt im russischen Layout привыт, im ukrainischen привіт. Beides sieht nach kyrillischen Wörtern aus, also schlägt Switch Please im Wörterbuch nach und nimmt das Wort, das es wirklich gibt.

Vergessenes Caps Lock

Aus hALLO wird Hallo, und Caps Lock wird ausgeschaltet. Absichtlich getippte Großbuchstaben bleiben stehen.

Merkt sich, was es lassen soll

Machen Sie eine automatische Korrektur einmal rückgängig, und dieses Wort wird nie wieder automatisch korrigiert. Praktisch für Nachnamen, Logins und Wörter in Sprachen, die das Programm nicht kennt.

Hält sich heraus

Passwortfelder, Vollbildspiele, Terminals, Code-Editoren und Passwortmanager bleiben standardmäßig unberührt.

Das Layout am Cursor

Auf Wunsch erscheint beim Layoutwechsel kurz ein kleines DE oder EN unter dem Textcursor.

Erste Schritte

  1. InstallierenStarten Sie SwitchPlease-Setup.exe. Es installiert sich nur für Sie, braucht keine Administratorrechte und bietet an, mit Windows zu starten.
  2. Das Symbol findenSwitch Please sitzt im Infobereich, das Symbol zeigt das aktuelle Layout. Nicht zu sehen? Es liegt unter dem Pfeil ^ — ziehen Sie es auf die Taskleiste.
  3. TippenFalsches Layout? Shift ×2 für das letzte Wort, Strg ×2 für die Auswahl oder die Zeile.

Datenschutz

Keine Telemetrie, keine Analyse, keine Absturzberichte, keine Lizenzprüfung. Die einzige Netzwerkanfrage ist die Update-Prüfung: Sie fragt GitHub nach dem Tag des neuesten Releases, sendet nichts über Sie und ist standardmäßig aus.

Nichts, was Sie tippen, verlässt Ihren Computer, und standardmäßig landen nur die Einstellungen auf der Festplatte. Der Quellcode ist offen — Einzelheiten in der README.
